Déclaration d’écoconception

Modèle de démonstration : ce texte doit être complété et validé par les équipes juridique et conformité avant toute mise en production.

Démarche

Ce portail est conçu selon les principes du Référentiel général d’écoconception de services numériques (RGESN) : faire simple, charger peu, calculer peu.

Mesures mises en œuvre

  • Aucun framework JavaScript : HTML sémantique et quelques kilo-octets de JavaScript par page.
  • Aucune bibliothèque, police, image ou script externe : polices système, icônes SVG intégrées, CSS Tailwind purgé.
  • Pas d’animation, de lecture automatique ni de vidéo.
  • Listes paginées et filtrées côté interface ; pas d’interrogation répétée du serveur (aucun polling).
  • Envoi de fichiers limité aux formats PDF et JPG, 20 Mo maximum, vérifié avant envoi.
  • Budget par page : moins de 100 Ko transférés (voir npm run budget).

Limites connues

Les documents sont envoyés tels quels : aucune compression côté navigateur n’est effectuée. Le dimensionnement de l’hébergement et la mesure d’impact en production restent à réaliser.
